# Explore With Me (Микросервисная архитектура)

Сервис для поиска и публикации событий, переведённый из монолита в микросервисную архитектуру на **Spring Cloud**. Пользователи создают события, подают заявки на участие, оставляют комментарии и формируют подборки; просмотры собираются в отдельном сервисе статистики.

---

## Состав системы

| # | Модуль | Назначение |
|---|--------|-----------|
| 1 | **`event-service`** | Управление событиями и категориями |
| 2 | **`user-service`** | Управление пользователями |
| 3 | **`request-service`** | Заявки на участие в событиях |
| 4 | **`comment-service`** | Комментарии к событиям |
| 5 | **`compilation-service`** | Подборки событий |
| 6 | **`stats-server`** | Сбор и хранение статистики просмотров |
| 7 | **`gateway-server`** | API Gateway — единая точка входа и маршрутизация |
| 8 | **`discovery-server`** | Eureka Server — реестр сервисов |
| 9 | **`config-server`** | Централизованное хранение конфигураций |
| 10 | **`common`** | Общие исключения и утилиты |

Каждый прикладной сервис имеет собственную базу данных PostgreSQL — общих таблиц между сервисами нет.

---

## Взаимодействие между сервисами

- **Регистрация и обнаружение.** Все сервисы регистрируются в **Eureka** (`discovery-server`). Клиенты находят инстансы по имени сервиса, без жёстко прописанных адресов.
- **Синхронные вызовы.** Общение реализовано через **OpenFeign**. Часть клиентов дополнена механизмами отказоустойчивости (fallback, Circuit Breaker).
- **Внутренние эндпоинты.** Контракты описаны в OpenAPI-спецификациях и находится в корне проекта (/openapi).
- **Внешний трафик.** Клиенты обращаются к **`gateway-server`**, который маршрутизирует запросы на нужный сервис через Eureka и LoadBalancer.
- **Конфигурация.** Настройки вынесены в **Config Server**; локально сервисы могут работать с профилем по умолчанию.

---

## Запуск

Сервисы запускаются по цепочке — от инфраструктуры к прикладным сервисам:

1. **`discovery-server`** — Eureka Server (реестр сервисов)
2. **`config-server`** — Config Server (централизованная конфигурация)
3. **`gateway-server`** — API Gateway (единая точка входа)
4. **`stats-server`** — сервис статистики
5. **`user-service`** — сервис пользователей
6. **`request-service`** — сервис заявок
7. **`event-service`** — сервис событий и категорий
8. **`comment-service`** — сервис комментариев
